# Sample Prompts

## Structure analysis (no copying)
"Analyze the structure of [URL] without copying any text/images/code. Output: sitemap, section list, layout types (grid/flex), approximate color palette (hex if visible), typography cues, spacing notes. Suggest original alternatives for a [niche] site."

## Component generation
"Generate Tailwind/HTML for a hero similar to [description], with original placeholder copy and royalty-free image slots. Include responsive layout and accessible labels."

## Original copy
"Write original marketing copy for a [niche] site inspired by [URL]’s layout: 3 headline options, 3 CTA options, 5 feature bullets. Tone: [tone]."

## No-code build guidance
"Give me a step-by-step to recreate [URL]’s layout in Framer/Webflow, replacing all assets with originals. Include key components, spacing, and responsive breakpoints."

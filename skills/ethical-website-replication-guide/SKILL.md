---
name: ethical-website-replication-guide
description: Guides ethical, legal website replication/inspiration when users request to clone/replicate a site (e.g., "clone web", "replicate [URL]", "make similar to [site]"). Uses AI + manual steps to recreate structure/flow/design without copying protected assets/content.
---

When a user asks to clone/replicate/build similar to a site (URL or description):
- Immediately give a one-time disclaimer: layout inspiration is fine; copying text/images/logos/unique graphics/proprietary code risks copyright/trademark issues. Always create original content and replace all media.
- Check red flags: verbatim copy requests; scrape/download assets; well-known trademarked brands; "exact clone/pixel-perfect/bypass copyright". If red flag: warn — "This crosses into potential infringement. I can only guide inspiration-only with original assets. Confirm?" Stop unless they agree.

Gather target info:
- Ask for URL if missing.
- Ask goal: learning, portfolio, own business, competitive analysis, redesign.
- Ask preferred stack/tool (Framer/Webflow/WordPress/HTML-CSS-Tailwind/React).

Analyze structure ethically (no asset/code copying):
- Use dev tools visually: layout (flex/grid), sections, nav, responsive behavior.
- Note flow: homepage → product → about → contact; hero, features, testimonials, footer.
- List components and approximate color palette/typography/spacing (choose your own equivalents).

AI-assisted planning (2026 hybrid):
- 10Web.ai: input URL → editable WP/Elementor layout → replace all text/images → rebrand.
- Hostinger AI: paste URL → similar structure → fully edit content.
- Framer AI / v0.dev-style: prompt "recreate layout similar to [site/description]" → editable design/code → replace content.
- LLM prompt example: "Analyze structure and component flow of [URL] without copying text/images/code. Output: sitemap, section list, layout type, approximate colors (hex if visible), font families. Suggest original alternatives for a [niche] site."
- Follow-up prompt: "Generate Tailwind/HTML for a similar hero with original placeholder content."

Manual rebuild (ethical fallback):
- Plan: sitemap (Relume AI/draw.io) → wireframe (Figma auto-layout) → build (stack of choice or no-code).
- Assets: use Unsplash/Pexels, Google Fonts, Iconify. Write original copy (or AI-generate fresh text).
- Test: responsiveness (mobile-first), accessibility (ARIA, contrast).

Delivery:
- Provide a step-by-step plan tailored to goal/stack.
- Include sample prompts.
- Remind: launch only with original assets; iterate in versions.

Edge cases:
- Public domain/open-source: closer reference OK.
- Own site: full clone OK.
- Portfolio practice: keep private/unpublished.

Keep responses concrete and actionable; never generate or suggest direct asset copies.

# Acceptance Criteria

## Project Purpose
Autonomous multi-agent engineering assistant.

## Initial Acceptance Criteria
- Repository scaffold exists with `docs/`, `src/`, `tests/`, and `ci/` directories.
- Agent contract exists at `docs/AGENT_CONTRACT.md`.
- Loop log exists at `docs/LOOP_LOG.md`.
- Decisions log exists at `docs/DECISIONS.md`.
- README exists at `README.md`.
- CI skeleton exists at `ci/pipeline.yml`.

## Quality Gates
- All required files are present and non-empty.
- All content is internally consistent and references the correct roles.
- No changes are made directly on the `main` branch.

## Explicit Stop Condition
Stop when all acceptance criteria and quality gates above are satisfied and validated.
